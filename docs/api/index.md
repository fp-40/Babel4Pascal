# API Reference

The public types and functions of each unit, with their declarations,
parameters, results and errors.

- [Core Functionality](core.md): locales (`TLocale`), identifiers,
  negotiation, the default locale, the locale data (`babel.core`,
  `babel.localedata`) and the exception classes (`babel.errors`).
- [Date and Time](dates.md): formatting and parsing of dates, times,
  intervals and durations, time zone names and time zone rules
  (`babel.dates`, `babel.tz`).
- [Languages](languages.md): the official languages of a territory
  (`babel.languages`).
- [List Formatting](lists.md): lists in the locale's styles
  (`babel.lists`).
- [Numbers and Currencies](numbers.md): formatting and parsing of
  numbers, currencies and percentages, currency data, exact decimals
  (`babel.numbers`, `babel.decimal`).
- [Pluralization Support](plural.md): plural rules and their operands
  (`babel.plural`).
- [General Support Functionality](support.md): `TFormat`, the formatting
  functions bound to a locale (`babel.support`).
- [Units](units.md): measurement units (`babel.units`).
